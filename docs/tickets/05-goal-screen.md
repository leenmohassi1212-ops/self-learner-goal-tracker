# 05 Goal screen

Why
The goal is the spine of the data model, and the waiting state is the only time edits are allowed, so the rules have to be enforced here, not remembered later (R2, R13, N11).

Done when
"AWS exam on a set date" and "finish a React course in four weeks" both save. A second active or waiting goal is refused. A waiting goal can be edited and abandoned (marked ended). Changing the deadline of a started goal is refused (N11). If the deadline passes while waiting, the goal ends by itself (R13).

Touches
S2 screen, goal routes, goal table.

# 06 Tasks

Why
Tasks carry the whole progress calculation and the timestamps the 48-hour clock runs on; the no-dodging rules live here (R3, R4, R13, A20).

Done when
Add, edit and reorder persist across logout and login. Deleting is refused after the goal starts, and for the last task while a confirmation request is out (R3, R8). Ticking (from the dashboard) records the exact time; the last tick asks for confirmation first (R13). Unticking clears it, takes the 48-hour clock back to the most recent task still ticked, and is refused on a completed goal (R4, R13). Ticking is refused while the goal is waiting (A20).

Touches
S3 screen, S4 tick control, task routes, task table.
